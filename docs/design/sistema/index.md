# Sistema de diseño

> Actualizada 2026-10-08

Documentación de la interfaz administrativa existente por petición del usuario. Los estilos del contenido público se definen en los documentos y Variables; no se confunden con el tema del editor. Las propuestas de funciones futuras siguen en DES-002 y SPEC-003.

**Tokens en el código:** assets/admin-theme.css, ámbito .mvl-admin-wrap y .mvl-content-cta. Las variantes sin token CSS se identifican explícitamente como valores de selectores.
