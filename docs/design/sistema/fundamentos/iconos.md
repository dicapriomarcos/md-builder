# Iconos

> Sistema de diseño · Actualizada 2026-10-08

Inventario de la implementación existente, documentado a petición del usuario; no introduce un rediseño adicional.

## Valores

| Variante | Recurso | Uso |
|---|---|---|
| Biblioteca | Dashicons de WordPress | Contenedor, Título, Texto, Botón e Imagen |
| Dispositivos | desktop, laptop, tablet, smartphone | Selector responsive |
| Selección de bloque | Icono de su tipo | Cabecera del inspector |

## Reglas

Los iconos decorativos llevan aria-hidden y los controles cuentan con nombre accesible. No introducir una nueva biblioteca para completar este diseño. El tamaño se define en los selectores existentes.
